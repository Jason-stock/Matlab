# 專案升級總結：波函數電子徑像距離增強的AO演算法

## 專案概覽

本專案是一個基於量子老鷹優化演算法 (Quantum Aquila Optimizer, QAO) 的複合模糊推理系統 (Composite Fuzzy Inference System, CFIS)，用於Mackey-Glass時間序列預測。主要創新是將**波函數生成電子的徑像距離**整合到優化演算法中。

## 主要更新內容

### 1. 新增文件

#### 1.1 核心演算法文件
- **`EQAO.m`** - 增強型量子老鷹優化演算法 (Enhanced Quantum Aquila Optimizer)
- **`EQAO_V2.m`** - 適用於統合FIS系統的EQAO版本
- **`EQAO_Mathematical_Expressions.md`** - 完整的數學表達式說明文件

#### 1.2 說明文件
- **`專案升級總結.md`** - 本文件，完整的更新說明

### 2. 修改文件

#### 2.1 原始QAO演算法增強
- **`QAO.m`** - 加入完整的波函數電子徑像距離模型
- **`AO.m` (V2版本)** - 對應的V2版本更新

#### 2.2 系統整合文件  
- **`optimizer.m`** - 修改為使用新的EQAO演算法
- **`main.m` (V2版本)** - 更新主程序調用EQAO_V2

## 核心技術創新

### 1. 波函數電子徑像距離模型

#### 數學基礎
```
ψ(r,θ,φ) = R_n(r) × Y_l^m(θ,φ)
P(r) = |ψ(r,θ,φ)|² × r² × dr
```

#### 多軌道疊加
```
P_total(r,t) = Σ c_i(t) × |R_{n_i}(r)|² × r²
```

其中權重 `c_i(t)` 動態調整：
- **初期 (t < 0.3T)：** 高能態主導 [0.2, 0.4, 0.4] - 偏重探索
- **中期 (0.3T ≤ t < 0.7T)：** 平衡分佈 [0.4, 0.4, 0.2] - 探索與開發平衡
- **後期 (t ≥ 0.7T)：** 基態主導 [0.7, 0.2, 0.1] - 偏重收斂

### 2. 量子效應整合

#### 2.1 電子自旋效應
```
spin_factor = (-1)^{隨機整數} ∈ {-1, +1}
```

#### 2.2 量子穿隧效應
```
P_tunnel = 0.05 (5%機率)
r_tunnel = -ln(U) × 2 (指數分佈)
```

#### 2.3 球面角度分佈
```
θ = arccos(2U₁ - 1) ∈ [0,π]
φ = 2πU₂ ∈ [0,2π]
```

### 3. 動態自適應機制

#### 3.1 量子強度調節
```
quantum_strength(t) = exp(-3t/T) + 0.2×sin(4πt/T)×exp(-2t/T)
```

#### 3.2 動態縮放因子
```
scale = S_base(t) × S_spin × S_position × S_quantum
```

#### 3.3 量子接受準則
```
P_accept = exp(-Δf / T_quantum) (類似量子退火)
```

## 演算法改進理由

### 1. **物理準確性提升**

**改進前：**
- 僅使用簡單的氫原子2s軌道
- 單一量子態，缺乏完整性
- 忽略角度分佈和自旋效應

**改進後：**
- 完整的多軌道疊加模型 (1s, 2s, 3s)
- 基於薛定諤方程精確解
- 包含球面角度分佈和電子自旋
- 引入量子穿隧和邊界反射

### 2. **搜索性能增強**

**探索階段 (早期)：**
- 高能態軌道主導 → 大範圍搜索
- 量子強度較高 → 強隨機性
- 穿隧機率增加 → 跳出局部最優

**開發階段 (後期)：**
- 基態軌道主導 → 精細搜索
- 量子強度衰減 → 穩定收斂
- 自適應邊界約束 → 保持可行性

### 3. **數學嚴謹性**

**理論基礎：**
- 基於量子力學基本原理
- 保持機率歸一化
- 滿足物理約束條件

**數值穩定性：**
- 邊界檢查和異常處理
- 參數範圍約束
- 數值精度控制

### 4. **演化適應性**

**時間相關權重：**
```
早期：探索權重大 → c = [0.2, 0.4, 0.4]
後期：收斂權重大 → c = [0.7, 0.2, 0.1]
```

**動態量子參數：**
- 量子強度隨時間衰減
- 接受機率動態調整
- 擾動幅度自適應
