## 核心數學表達式

### 1. 多軌道波函數模型

#### 1.1 氫原子1s態徑向波函數
```
R₁₀(r) = 2(1/a₀)^(3/2) × exp(-r/a₀)
```

#### 1.2 氫原子2s態徑向波函數
```
R₂₀(r) = (1/2√2)(1/a₀)^(3/2) × (2-r/a₀) × exp(-r/2a₀)
```

#### 1.3 氫原子3s態徑向波函數
```
R₃₀(r) = (2/27√3)(1/a₀)^(3/2) × (27-18r/a₀+2r²/a₀²) × exp(-r/3a₀)
```

#### 1.4 徑向機率密度函數
```
P₁ₛ(r) = |R₁₀(r)|² × r² × dr = 4r² × exp(-2r/a₀)
P₂ₛ(r) = |R₂₀(r)|² × r² × dr = (r²/8a₀³) × (2-r/a₀)² × exp(-r/a₀)
P₃ₛ(r) = |R₃₀(r)|² × r² × dr = (4r²/729a₀³) × (27-18r/a₀+2r²/a₀²)² × exp(-2r/3a₀)
```

#### 1.5 統計分佈
```
r₁ₛ ~ Gamma(k=3, θ=a₀/2)
r₂ₛ ~ 複合分佈（需要特殊採樣）
r₃ₛ ~ Gamma(k=4, θ=9a₀/8)  // 近似分佈
```
其中 a₀ = 1 (歸一化波爾半徑)

#### 1.6 動態軌道權重
根據演化進度動態調整各軌道權重：
```
早期 (t < 0.3T): w = [0.2, 0.4, 0.4]  // [1s, 2s, 3s]
中期 (0.3T ≤ t < 0.7T): w = [0.4, 0.4, 0.2]
後期 (t ≥ 0.7T): w = [0.7, 0.2, 0.1]
```

### 2. AO四段策略整合

#### 2.1 策略1 (S1): 高空盤旋 + 多軌道量子探索
```
X_base = X_best × (1 - t/T) + r₁ × (X_best - r₂ × X_best)
X_new = X_base + d⃗ × r_exploration × α_adaptive × ε_exploration × spin

其中：
r_exploration = w₁×r₁ₛ + w₂×r₂ₛ + w₃×r₃ₛ + exploration_boost
exploration_boost = 1 + 0.3 × U[0,1]
ε_exploration = 0.5 × (1 - (t/T)^0.5)
```

#### 2.2 策略2 (S2): 低空滑翔 + 平衡軌道量子引導
```
X_base = X_mean - A × |X_rand - X_i|
X_new = X_base + d⃗ × r_balanced × α_adaptive × ε_gliding × spin

其中：
r_balanced = w₁×r₁ₛ + w₂×r₂ₛ + w₃×r₃ₛ
ε_gliding = 0.3 × exp(-t/T)
```

#### 2.3 策略3 (S3): 俯衝攻擊 + 基態量子收斂 + 穿隧
```
if rand < P_tunnel:  // 15%穿隧機率
    X_new = X_base + d⃗ × (r_ground + r_tunnel) × α_adaptive × ε_attack × spin
else:
    X_new = X_base + d⃗ × r_ground × α_adaptive × ε_attack × spin

其中：
X_base = X_best - A × |X_best - X_i|
r_ground = 0.8 × r₁ₛ  // 收斂因子
r_tunnel = tunnel_direction × 0.5 × exp(-r_radial/2) × (-ln(U))
ε_attack = 0.2 × (1 - (t/T)²)
P_tunnel = 0.15
```

#### 2.4 策略4 (S4): 包圍攻擊 + 量子Lévy混合飛行
```
X_new = X_best + A × hybrid_step + d⃗ × r_radial × α_adaptive × ε_surround × spin

其中：
hybrid_step = 0.7 × levy_classical + 0.3 × levy_quantum
β_quantum = 1.5 + 0.3 × sin(θ)
σ_quantum = σ_base × (1 + 0.1 × ln(1 + r_radial))
levy_quantum = (u/|v|^(1/β)) × (1 + 0.2 × cos(φ) × spin)
ε_surround = 0.4 × (1 - (t/T)^1.5)
```

### 3. 演化進度自適應調整

#### 3.1 自適應縮放因子
```
α_adaptive(t) = α_base(t) + α_oscillation(t)
```

#### 3.2 基礎衰減項
```
α_base(t) = 0.3 × exp(-2t/T)
```
提供主要的時間衰減，確保量子擾動隨演化進度減弱。

#### 3.3 振盪調制項
```
α_oscillation(t) = 0.1 × sin(3πt/T) × exp(-t/T)
```
提供中期微調，避免過早收斂。

#### 3.4 最小量子效應保證
```
α_adaptive(t) = max(α_adaptive(t), 0.02)
```
確保在演化後期仍保持最小的量子效應。

### 4. 量子方向向量與自旋效應

#### 4.1 球面均勻分佈
```
θ = arccos(2U₁ - 1) ∈ [0,π]    // 極角
φ = 2πU₂ ∈ [0,2π]              // 方位角
```

#### 4.2 笛卡爾坐標轉換
```
d_x = sin(θ)cos(φ)
d_y = sin(θ)sin(φ)  
d_z = cos(θ)
```

#### 4.3 高維擴展
```
d⃗ₖ = d_{(k-1)mod3 + 1}, k = 1,2,...,dim
```

#### 4.4 電子自旋效應
```
spin = (-1)^{隨機整數} ∈ {-1, +1}
```
自旋影響所有縮放因子，提供探索的隨機性和方向性。

### 5. 量子穿隧機制

#### 5.1 穿隧條件
```
P_tunnel = 0.15  // 在S3階段的穿隧機率
```

#### 5.2 穿隧強度計算
```
tunnel_strength = 0.5 × exp(-r_base/2)
tunnel_direction = ±1
tunnel_boost = direction × strength × (-ln(U))
```

#### 5.3 穿隧效應的物理意義
- **能量屏障穿越：** 幫助跳出局部最優
- **概率性躍遷：** 維持量子特性
- **方向隨機性：** 增強探索能力

### 6. 完整更新公式

整合後的AO位置更新公式：
```
X_new^(t+1) = AO_strategy^(t) + d⃗(θ,φ) × r_orbital × α_adaptive(t) × ε_stage(t) × spin
```

其中：
- `AO_strategy^(t)` 是原始AO四段策略
- `d⃗(θ,φ)` 是量子方向向量  
- `r_orbital` 是多軌道加權徑向距離
- `α_adaptive(t)` 是演化自適應因子
- `ε_stage(t)` 是階段特定因子
- `spin` 是電子自旋因子 (±1)
