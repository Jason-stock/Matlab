## 整合後的四段策略數學模型

### 策略1 (S1): 高空盤旋 + 多軌道量子探索 (t < 0.25T)

**基礎策略：**
```
X_base = X_best × (1 - t/T) + r₁ × (X_best - r₂ × X_best)
```

**量子增強：**
```
X_new = X_base + d⃗(θ,φ) × r_exploration × α_exploration

其中：
r_exploration = 0.5 × r₂ₛ + 0.4 × r₃ₛ + exploration_boost
exploration_boost = 1 + 0.3 × U[0,1]
α_exploration = 0.5 × (1 - (t/T)^0.5) × spin
```

**軌道特性：** 主要使用高能態軌道（2s, 3s），提供大範圍探索能力

### 策略2 (S2): 低空滑翔 + 中等軌道量子引導 (0.25T ≤ t < 0.5T)

**基礎策略：**
```
X_base = X_mean - A × |X_rand - X_i|
```

**量子增強：**
```
X_new = X_base + d⃗(θ,φ) × r_balanced × α_gliding

其中：
r_balanced = 0.6 × r₁ₛ + 0.4 × r₂ₛ
α_gliding = 0.3 × exp(-t/T) × spin
```

**軌道特性：** 使用1s和2s的平衡組合，兼顧探索和收斂

### 策略3 (S3): 俯衝攻擊 + 基態量子收斂 (0.5T ≤ t < 0.75T)

**基礎策略：**
```
X_base = X_best - A × |X_best - X_i|
```

**量子增強（含穿隧）：**
```
if rand < 0.15:  // 15%穿隧機率
    X_new = X_base + d⃗(θ,φ) × (r_ground + r_tunnel) × α_attack
else:
    X_new = X_base + d⃗(θ,φ) × r_ground × α_attack

其中：
r_ground = 0.8 × r₁ₛ  // 收斂因子
r_tunnel = sign(±1) × 0.5 × exp(-r_radial/2) × (-ln(U))
α_attack = 0.2 × (1 - (t/T)²) × spin
```

**軌道特性：** 主要使用基態軌道（1s），精確收斂，加入量子穿隧

### 策略4 (S4): 包圍攻擊 + 量子-Lévy混合飛行 (t ≥ 0.75T)

**混合Lévy飛行：**
```
X_new = X_best + A × hybrid_step + d⃗(θ,φ) × r_radial × α_surround

其中：
hybrid_step = 0.7 × levy_classical + 0.3 × levy_quantum
α_surround = 0.4 × (1 - (t/T)^1.5) × spin
```

**量子Lévy飛行：**
```
β_quantum = 1.5 + 0.3 × sin(θ)
σ_quantum = σ_base × (1 + 0.1 × ln(1 + r_radial))
levy_quantum = (u/|v|^(1/β)) × (1 + 0.2 × cos(φ) × spin)
```

## 核心量子參數模型

### 1. 電子軌道採樣函數

#### 1s軌道（基態）
```
R₁₀(r) = 2(1/a₀)^(3/2) × exp(-r/a₀)
P₁ₛ(r) = 4r² × exp(-2r/a₀)  ≡ Gamma(3, a₀/2)
```

#### 2s軌道（第一激發態）
```

P₂ₛ(r) = (r²/8a₀³) × (2-r/a₀)² × exp(-r/a₀)
```

#### 3s軌道（第二激發態）

**球面均勻分佈：**
```

```
